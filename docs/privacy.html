Privacy

Local records, clear boundaries

Last updated August 20, 2026

Pew Pew Collection is designed so the application vendor does not receive your firearm inventory.

The self-hosted application

Your inventory, photos, local administrator, sessions, and generated session secret are stored in the /data directory you mount into the container. The application has no telemetry. Its GitHub release check is optional and disabled by default.

You operate the server and control its network, logs, backups, reverse proxy, and any third-party services you add. Those systems may have their own privacy behavior. Encrypt sensitive backups and avoid exposing the app directly to the public internet.

This documentation website

The static documentation pages do not include analytics, advertising pixels, third-party fonts, or live badge images. GitHub Pages and links you choose to follow are governed by their operators' policies.

Questions

Open a GitHub issue for a general privacy question. Report sensitive security concerns through the project's GitHub security page.
