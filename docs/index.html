Your inventory stays on your hardware

The app sends nothing by default

The app needs the network once, to pull its image. It has no telemetry, and the release check stays off until you turn it on.

The inventory lives in one directory

The SQLite database holds inventory records, sessions and attached PDFs. Photos and the generated session key live beside it under /data. Back up that directory, then test a restore.

Server security stays with you

You keep Docker and the app current, put HTTPS in front of remote access and encrypt your backups.

Read the security guide

Compared with a spreadsheet or a cloud app

A cloud app syncs across devices with nothing to set up. Pew Pew Collection makes the opposite trade: you keep the data, and you run the server.

Questions

Does the app report my collection to anyone?

No. Pew Pew Collection has no reporting and no telemetry. The one built-in outbound request is an optional GitHub release check, and it is off by default.

Does self-hosting change legal access to my records?

It removes the app vendor as a custodian of your inventory. It does not make records immune from lawful access, device seizure or disclosure duties. Those depend on where you live; ask a qualified attorney.

Is my inventory lost if a hard drive fails?

No, if you keep a backup. Copy the whole /data directory while the container is stopped, keep a second encrypted copy somewhere else, and test a restore before you need one.

Why use an app over a spreadsheet?

A spreadsheet works, and many collectors start there. The app adds unique serial numbers, search and filters, the insurance report with totals, and disposition records for firearms sold, lost or stolen.

Does the app work without internet?

Yes. After the first Docker pull the app runs offline. Setting UPDATE_CHECK=true turns on a check for new releases on GitHub; it is off by default.

Is the app free?

Personal, noncommercial self-hosted use costs nothing under the Business Source License 1.1. Other production use may need a commercial license. The code converts to Apache 2.0 on the license's change date.

How do I import a spreadsheet inventory?

Use the built-in CSV import. Match your columns to the field names in the import dialog, then import the file.

Where are photos stored?

Photos are stored in /data/photos on your own disk, up to 12 per firearm. Backing up the data directory captures the database and the photos together.

Install Pew Pew Collection in 3 steps

  1. 1. Run the container

    The image comes from GitHub Container Registry. You need no Docker Hub account.

  2. 2. Read the setup code

    docker logs ppcollection prints a one-time code on a fresh install.

  3. 3. Create your account

    Open http://localhost:3000, enter the code and choose a username and password.

When you update, recreate the container with the same /data mount. If first-run setup shows again after an update, stop and restore the original mount before you add records.

Read the configuration guide

Docker run
docker run -d \
  --name ppcollection \
  -p 3000:3000 \
  -v /srv/ppcollection/data:/data \
  --restart unless-stopped \
  ghcr.io/gogorichielab/ppcollection:latest
Docker Compose
services:
  ppcollection:
    image: ghcr.io/gogorichielab/ppcollection:latest
    ports:
      - "3000:3000"
    volumes:
      - ./data:/data
    restart: unless-stopped
